# Laufplan

Öffentliche Handyansicht mit Trainingsplan, Zielen und aggregierten Fortschrittsgrafiken.

Enthält freigegebene Pace-, Puls-, Kadenz- und Intensitätswerte sowie Clubbesuche. Keine privaten Trainingsnotizen, Schlafdaten oder vollständigen Tagebücher. Die Quelldaten und der Export bleiben lokal.

GitHub Pages veröffentlicht den Stand auf `main` automatisch.
